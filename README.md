## 🎮 Using Perch

Now that Perch is installed, let's explore how to use its amazing features.

### ⌨️ The Magic Shortcut: Ctrl+Space

This is your new best friend. Press **Ctrl+Space** anywhere in macOS, and a sleek search bar appears. Start typing:

- **App name** (like "Safari" or "Messages") → Press Enter to launch it
- **Window title** (like "Quarterly Report.docx") → Press Enter to switch to that window

It's that fast. No mouse needed, no hunting through menus.

### 🪟 Switching Windows

Have multiple windows open in the same app? Perch makes switching a breeze:

1. Press **Ctrl+Space**
2. Type part of the window's title
3. Select the window you want and press Enter

You'll be instantly transported to that window, ready to work.

### 📊 Checking System Health

Want to see how your Mac is doing? Just click the Perch icon in your menu bar (it looks like a small bird or perch—you'll find it on the top right of your screen).

A beautiful Liquid Glass popup appears showing:
- **CPU usage** (how busy your processor is)
- **Memory usage** (how much RAM is being used)
- **Other system stats** (depending on your Mac's capabilities)

This is perfect for those moments when your Mac feels sluggish—you can quickly see what's using resources.

## 🧰 Troubleshooting Common Issues

Even great software occasionally needs a helping hand. Here are solutions to common problems:

### "Perch Won't Open"

1. Check your Downloads folder to ensure the file downloaded completely
2. Try moving Perch to Applications again (drag it out, then back in)
3. Restart your Mac and try again

### "Perch Doesn't Respond to Ctrl+Space"

1. Make sure Perch is running (look for its icon in the menu bar)
2. Click the Perch icon, select **Preferences**, and re-set the shortcut
3. Check that no other app is using the same shortcut

### "System Monitor Shows No Data"

1. Go to System Settings → Privacy & Security
2. Look for Perch in the list
3. Ensure all toggles are enabled

### "Perch Is Slow"

- Close other resource-hungry apps
- Check that you're running a supported version of macOS
- Restart Perch by quitting it (click icon → Quit) and reopening
